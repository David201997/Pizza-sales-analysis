# 🍕 Pizza Sales Analysis – MySQL Project

## 📌 Project Overview

This project analyzes pizza sales data using MySQL. 
The objective is to explore sales performance, customer ordering patterns,
popular pizzas, and revenue trends using SQL queries.

## 🎯 Project Objectives

- Analyze overall pizza sales performance
- Find total revenue generated
- Identify the best-selling pizzas
- Analyze orders by date and time
- Find the most popular pizza categories
- Calculate average order value
- Identify sales trends
- Generate useful business insights from the data

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## 🗄️ Database Structure

The project contains tables such as:

- `orders`
- `order_details`
- `pizzas`
- `pizza_types`

## 📊 SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- JOIN
- LEFT JOIN
- Subqueries
- CASE Statements
- Date & Time Functions
- LIMIT

## 🔍 Key Analysis

Some of the questions answered in this project include:

1. What is the total number of orders?
2. What is the total revenue generated?
3. What is the average order value?
4. What is the total quantity of pizzas sold?
5. Which pizza is the best-selling?
6. Which pizza category generates the most revenue?
7. What are the busiest ordering times?
8. What are the daily and monthly sales trends?
9. Which pizzas contribute the most to total revenue?

## 📁 Project Files

- `pizza_sales_project.sql` – Contains database creation, table creation, and SQL analysis queries.
- `README.md` – Project documentation.

## 💡 Key Insights

The SQL analysis helps identify:

- Top-performing pizzas
- Highest-revenue pizza categories
- Customer ordering patterns
- Peak sales periods
- Overall business performance

## 🚀 Conclusion

This project demonstrates how MySQL and SQL can be used to analyze
real-world sales data and generate meaningful business insights.

The project also demonstrates practical knowledge of database creation,
data analysis, aggregation, joins, filtering, and business-oriented SQL queries.
